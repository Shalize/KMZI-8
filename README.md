Практическая работа 8. ГОСТ 34.10-2012.
В репозитории есть два файла с кодом, обы нужны. 
В файле create_test_files.py реализованы функции создания тестового документа для тестирования сценария с подписанием документа, а также вычисления хэша этого файла.
В файле practical_work.py реализована схема подписания ЭЦП по ГОСТ 34.10-2012.
Сначала нужно запустить create_test_files.py, затем основную реализацию practical_work.py.
При запуске основной реализации программа запросит сценарий, по которому пользователь может пойти.
После создания тестового файла и файла с хэшем рекомендуется выбрать 3 (сценарий генерации ключевой пары). Ключи будут сгенерированы двумя файлами в той же папке, что и тестовый файл и файл с его хэшом.
Затем нужно выбрать 1 (сценарий подписания файла сгенерированным закрытым ключом). Указать путь к сгенерированному тестовому файлу.
Затем нужно выбрать 2 (сценарий проверки подписи с помощью сгенерированного открытого ключа). Указать путь с подписанному в сценарии 1 тестовому файлу. ЭЦП должна быть верна.
Координаты точки эллиптической кривой взяты из ГОСТ 34.10-2012, не рандомные.
